# 黄白样板视频逐帧校正报告

## 结论先行

之前的实现方向有根本性误读。样板明确要求的是一套滚动网站的 **6 张独立完整屏幕**，每张屏幕对应网站从首屏到收尾的一个阶段；不是一张网页里放一个 3D 模型，再让模型随着滚动旋转。第二个视频展示的是如何把这些独立屏幕用连续滚动、视差、切换和镜头运动连接起来。

## 视频二：`ce8e073e43714b4604e7903aeb00a9b1.mp4`

已读取本地视频的 12 张关键帧和 contact sheet。它不是另一个古塔样板，而是 OJO/视差网站的制作与展示教程：

- 鼠标滚动驱动页面，而不是点击切换页面。
- 画面中的主体、文字、背景和镜头同时移动。
- 设计稿以完整屏幕为单位，滚动只是把六个屏幕连续连接起来。
- 视差来自前景、中景、背景不同速度，不是单纯把模型上下移动。
- 页面需要有开场、内容推进、作品展示、导航和收尾闭环。

## 对当前作品的差距

当前作品已经有可旋转 WebGL 模型、章节高度和单一模型的滚动进度，但仍然缺少样板要求的核心交付：

1. 没有先设计并交付六张独立完整屏幕。
2. 飞英塔没有六个独立镜头构图。
3. 文字、编号、导航、模型和背景没有以屏幕为单位统一设计。
4. 滚动目前主要改变模型的相机/拆解量，没有真正切换六个视觉阶段。
5. 没有建立前景、中景、背景三层视差系统。
6. 当前 Lux3D 模型仍承担了页面设计、镜头设计和叙事，导致画面像组件展示。

## 正确制作顺序

### A. 先做六张独立屏幕设计稿

飞英塔先制作：

1. **封面屏**：远景塔 + 天空/环境 + 主标题 + 编号。
2. **整体屏**：完整塔的英雄视角 + 结构说明。
3. **外塔屏**：七层外塔/八面相连的环形或楼层视角。
4. **斗拱屏**：木构斗拱近景，强调年轮、边缘、光泽和阴影。
5. **塔中塔屏**：外塔拆开，五层石塔显现。
6. **收尾屏**：完整塔回归 + 文化信息 + 导航/下一章节。

### B. 再把六张屏幕做成一个连续滚动

- 每张屏幕占一个固定视口高度。
- 使用 GSAP ScrollTrigger pin + scrub 连接屏幕。
- 每个屏幕有独立 camera pose、背景、文字布局和模型状态。
- 屏幕之间使用遮罩、深度位移、缩放、横向漂移和透明度交叉，而不是只修改一个 `progress`。
- 为每一屏添加可审查的编号和截图输出。

### C. 最后才做模型细节和材质精修

- 近景屏使用专门镜头和灯光。
- 木材使用方向性纹理、粗糙度变化和边缘高光。
- 瓦片使用颗粒、灰尘、轻微破损和冷色反射。
- 石塔使用孔隙、风化、暗部和低反射。
- 拆解屏保证外塔七层、斗拱、飞檐、内塔五层的层次关系可读。

## 本报告的使用规则

在六张独立屏幕设计稿通过前，不继续扩展其他展品，也不再把当前的单模型滚动版本称为样板级完成品。
