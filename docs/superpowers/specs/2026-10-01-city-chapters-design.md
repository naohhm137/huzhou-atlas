# 层见湖州 · 从器物走向城市

## 目标

保持现有四件 Blender 展品、首屏影片及拆解流程，在飞英塔之后加入四处真实地点：衣裳街、东吴银泰双子大厦（东吴国际广场双子塔）、太湖龙之梦、南浔古镇。游客从“手中之物”走向“城市空间”，最后回到水乡。只更新本地作品，等待用户验收后再讨论公网发布。

## 故事与画面

延续深绿、纸色、黄铜、纪实照片和宋体标题。新半程不是四个重复的展品，而是四种空间尺度：

1. **衣裳街 · 人的尺度**：夜间街巷全幅照片，青莲桥作为第二视角。滚动推进街心透视；“街巷／河埠”按钮切换两张真实影像。画面叠加轻微的门框式边界，不模拟不存在的古街原貌。
2. **东吴双塔 · 天际线尺度**：白日实景双塔，滚动令两座竖向图像窗从不同高度显影，细线标出双塔轮廓与城市水岸关系。点击“近看立面”切换另一张实景照片，避免程序化重建不准确的建筑。
3. **太湖龙之梦 · 游乐尺度**：确有来源的国际马戏城门面作为龙之梦景区一隅，图片保持本身彩度；以克制的环形舞台遮罩及纵深位移展开。文案明确所示为园区一角，不声称全园全景。
4. **南浔古镇 · 水乡尺度**：与封面不同的河巷实景，以两张同地不同角度照片作拖动对照，收束“新的城市也由旧水脉串连”。对照控件支持键盘、触控和鼠标；不是历史前后对比。

地点段落使用 CSS sticky 与一个现有 ScrollTrigger 进度导体，保持原生可逆滚动。每节有不同主动作，但它们的镜头运动只用小幅视差、遮罩与曝光层次，不做连番大缩放、不劫持滚轮。减少动态效果时保留照片、文字和直接操作，移除滚动插值。

## 内容边界与来源

新增照片均取自 Wikimedia Commons，保留作品页、作者、许可与改编说明。衣裳街和青莲桥、龙之梦国际马戏城：源義信 / CC BY-SA 4.0；双塔近景：钉钉 / CC BY-SA 4.0；双塔远景：Mathewstory / CC BY-SA 4.0；南浔河巷两景：Stefan Fussan / CC BY-SA 3.0。网站会显示简短署名并在页脚逐张链接作品页与许可。照片是实景，任何线框和动画仅作视觉导览。不得添加未经证实的年代、高度或复原声称。

## 兼容与验收

- 四件原有 3D 展品和展开、旋转、滚动拆层维持工作。
- 修复 601–900px 宽度下展品照片说明与章节副标题交叠：说明移到安全区域或隐藏，且复制文案不被舞台覆盖。
- 导航可到达所有新增地点，在窄屏不挤出屏幕；支持键盘焦点和锚点偏移。
- 桌面 1440、中屏 768、手机 390/360 宽度逐章视觉检查；向下、向上、跳转、控制点击和 reduced motion 均可读；控制台无错误、图片无失载。
- 本地预览仍使用 `127.0.0.1:4173`；不推送 GitHub、不发布公网。

## 技能决策

`find-skills` 搜得 MengTo 的 `cinematic-scroll-storytelling`（约 1.5K 安装、GitHub 约 6.5K stars）及 `scroll-world-storytelling`（约 1.1K 安装）。采用其“单一故事弧、原生可逆滚动、逐场景独特运动、手机和 reduced-motion 复验”原则；本项目已有 GSAP，不引入 Lenis 或预加载遮罩，以免破坏原有影片逐帧映射与滚动手感。用户明确授权自决，因此不另设方向审批轮。
