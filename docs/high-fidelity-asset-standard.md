# 高精度展品统一标准

本项目所有展品（飞英塔、湖笔、双林织机、顾渚茶器及后续展品）必须达到同一视觉门槛：

- 主体使用 Aholo Lux3D 生成的高细节网格与材质作为完整展示主体。
- Blender 只负责语义拆分、结构解释、剖面和可控动画，不代替 Lux3D 的材质细节。
- 每个物体必须保留可读的颗粒、法线、粗糙度变化、边缘高光、磨损和比例细节。
- Three.js 使用 PBR/Physical 材质、环境反射、法线贴图、粗糙度贴图和近景灯光；近景镜头必须单独调光。
- 每件展品先设计六张独立完整屏幕，再用 GSAP ScrollTrigger/OJO 式连续滚动连接。
- 每屏逐项审核：模型比例、镜头、文字安全区、背景层次、颗粒清晰度、光泽度和遮挡关系。
- 未通过逐屏截图审核，不进入下一件展品，也不得称为完成。

飞英塔当前作为材质与镜头基准，湖笔、织机、茶器和后续城市展品必须按同一标准复核和升级。
