# 层见湖州｜湖州文化漫游

一个可直接部署的静态网站。南浔实景与原创抽象影像随滚动逐帧变化；湖笔、双林水平织机、顾渚茶器、飞英塔四组在 Blender 制作的 3D 展品可点击拆解、合拢并拖动旋转。其后从器物走向城市，加入衣裳街、东吴银泰双子大厦、太湖龙之梦国际马戏城、南浔古镇四处实景互动章节。页面提供章节导航、逐图署名和降低动态效果的适配。完整 Blender 源文件、摄影门面贴图和可复现构建脚本随项目保留。

## 运行

需要 Node.js 20.19+ 与 pnpm。

```bash
pnpm install
pnpm dev
```

浏览器打开命令行显示的本地地址。发布时运行 `pnpm build`，将 `dist/` 的内容放到静态网站服务器即可；`pnpm preview` 可本地预览构建结果。请使用 HTTP 服务打开，不要直接双击 `index.html`。

## 体验方式

- 向下或向上滚动：影像跟随滚动位置前进或回退；章节内的 3D 部件先轻微分离。
- 点击“拆开展品”：进入全屏剖览并完整拆解；点击右上角“合拢展品”或按 Esc 返回。此操作会优先于该章节的滚动拆解状态。
- 在模型上拖动：改变观察角度；展开态用滚轮可近看细节。顶部导航可直达四组展品及新增城市地点；窄屏用“目录”打开章节表。
- 在衣裳街、双塔、龙之梦切换实景视角；在南浔拖动分界或聚焦后用左右方向键观察同一古镇的两个河巷角度。滚动场景均可反向恢复；这些照片并非历史前后对照。

影片是本项目制作的 10 秒无声 H.264 影像（1280×720、24 fps、0.5 秒关键帧间隔），不是外链视频。开篇 poster 与影片首帧相同，影像在开篇结束后才进入暗色墨化，避免突变。3D 展品是解释工艺结构的原创数字示意，不是文物扫描件。四件 GLB 内嵌了在 Blender 生成的竹、木、丝、釉、瓦、石等基色／粗糙度／法线贴图，网页用环境反射与展厅布光呈现。湖笔只有一根竹杆和一整束笔锋；展开后的茶汤是透明浅液层，不是第二只茶盏。飞英塔外塔前方开间是**观察剖面**，并非现实塔身缺损。Blender 源文件在 `assets/blender/sources/`；可复现的建模脚本在 `assets/blender/build_exhibits.py`；网页加载 `public/models/` 中保留独立分件的 GLB。主要界面代码在 `src/site.tsx`、`src/storyTiming.ts`、`src/exhibits.ts`、`src/modelAsset.ts` 和 `src/style.css`。`src/models/` 是上一版程序化模型，仅保留为参考，不参与当前页面渲染。

运行 `pnpm test` 可检查视频时间映射、GLB 节点与拆解数据、织机独立经丝、茶汤分层、飞英塔“塔中塔”结构，以及城市章节顺序和南浔键盘对照；运行 `pnpm build` 构建生产文件。重建模型时使用 Blender 4.2：`blender -b --python assets/blender/build_exhibits.py`，从项目根目录运行。

## 来源与许可

开篇南浔照片来自 [Stefan Fussan 的 Wikimedia Commons 作品](https://commons.wikimedia.org/wiki/File:Nanxun_-_Ancient_water_town_-_0081.jpg)，原照片与基于它制作的影片按 [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) 署名与相同方式共享。影像的墨线、丝线、茶叶段为本项目程序化绘制。章节背景采用 Wikimedia Commons 的毛笔材质、传统织机、长兴茶园和飞英塔内部照片；它们各自的作者、许可和原图链接已在网站页脚标明。毛笔和织机背景只作材质／工艺参考，不能当作湖笔或双林织机实物。器物形制及飞英塔结构的研究链接与取舍见 [REFERENCE_RESEARCH.md](REFERENCE_RESEARCH.md)。

网页代码和程序化 3D 模型由本项目创作。若进一步用于商业传播，请分别核对字体服务、第三方内容与图片许可要求。

新增城市实景照片共八张，逐图作者、作品页和许可在网站页脚及 [REFERENCE_RESEARCH.md](REFERENCE_RESEARCH.md) 列出。页面对照片做了裁切、颜色层和滚动遮罩；龙之梦照片只代表园区内的国际马戏城，不是整个园区全景。新界面位于 `src/CityChapter.tsx` 与 `src/cityScenes.ts`，没有改动四件 `.blend` 和 `.glb` 展品。

## 2026-10-09 材质与发布

八组模型已重新生成 1024px 基色、粗糙度和法线贴图。衣裳街加入透视校正的实景门面纹理，青瓷有独立釉层，茶叶有连续曲面与厚度。网页在斜视角开启各向异性过滤，并按屏幕尺寸控制龙之梦细肋显示，避免远景闪烁。

Render 可读取根目录 render.yaml；构建使用 Node 24、锁定 pnpm 版本，发布目录为 dist。材质细节仍为实景参照的作者重建，不能当作扫描或测绘数据。完整要求与检查见 QUALITY_REQUIREMENTS_2026-10-09.md。
